`clip-path`는 요소의 **보이는 영역**을 잘라내는 CSS 속성입니다. 요소 자체는
그대로 있지만, 지정한 도형 바깥 부분은 화면에 그려지지 않습니다.

말로 설명하는 것보다 직접 보는 게 빠릅니다. 아래 버튼을 눌러보세요.

<ClipPathPresetDemo />

버튼을 누를 때 부드럽게 변하는 것도 눈여겨보세요. `clip-path`는 CSS
`transition`으로 애니메이션할 수 있는 속성이라, 이 데모는 다음 한 줄이
전부입니다.

```css
.box {
  clip-path: inset(50% 0 0 0);
  transition: clip-path 0.6s cubic-bezier(0.32, 0.72, 0, 1);
}
```

## inset()

가장 자주 쓰게 되는 함수는 `inset()`입니다. 위·오른쪽·아래·왼쪽에서
얼마나 잘라낼지를 지정하는데, `padding`과 같은 순서라 외우기 쉽습니다.

```css
/* 위에서 50% 잘라내기 */
clip-path: inset(50% 0 0 0);

/* 네 방향 모두 20% 잘라내고, 모서리를 24px 둥글게 */
clip-path: inset(20% round 24px);
```

`round` 키워드가 특히 재밌는 부분입니다. 잘라낸 영역의 모서리를
`border-radius`처럼 둥글릴 수 있거든요. 슬라이더를 움직여 보세요.

<InsetSliderDemo />

`inset(0% round 9999px)`에서 시작해 `inset(0% round 0)`으로 트랜지션하면,
원에서 사각형으로 변하는 모프 애니메이션도 만들 수 있습니다.

## 어디에 쓸까

`clip-path`가 빛나는 순간들:

- **리빌(reveal) 애니메이션** — 이미지나 섹션이 커튼 걷히듯 나타나는 효과
- **before/after 비교 슬라이더** — 두 이미지를 겹쳐두고 한쪽을 잘라내기
- **탭 전환 효과** — 활성 탭 모양대로 배경을 잘라내 미끄러지듯 이동시키기

다음 글에서는 이 중 비교 슬라이더를 직접 만들어보겠습니다.
